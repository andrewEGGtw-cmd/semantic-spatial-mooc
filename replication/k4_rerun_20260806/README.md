# k = 4 重現紀錄（2026-08-06）

## 目的
補齊論文表 4-6 之 pseudo R² 欄。硬碟上原有的 `analysis_pipeline/outputs/*` 是 **k = 10** 的舊批次
（`config.py` 之 `KNN_MAIN = 10`、`KNN_LIST = [5, 10]`），數值與論文表 4-3／4-4／4-6 不符，
不可直接引用。本資料夾以相同資料與相同程式邏輯，改以 **k = 4** 重跑並驗證可完整重現論文數字。

## 輸入（未修改）
- `outputs/analysis_panel.csv`（175 門，2021–2025 summer）
- `outputs/course_embeddings.npy`（175 × 384，paraphrase-multilingual-MiniLM-L12-v2）

## 程式
| 檔案 | 內容 |
